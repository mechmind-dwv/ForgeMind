# ForgeMind 0.8.0 — Compositional Scientist

ForgeMind 0.8 separates two roles:
- Generators propose compact compositional hypotheses.
- Falsifiers search for counterexamples.

The arena also tracks:
- hypothesis complexity
- empirical support
- falsification count
- disagreement/information value
- hidden-test generalization

This is an experimental program-synthesis sandbox, not a claim of intelligence.
